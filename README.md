# Binary-vs.-Interpolation-search
# Analysis of Algorithms - Lab 05 

## Description
This repository contains the C++ implementations for Lab 05 of the Analysis of Algorithms course at the School of Mathematical and Computational Sciences, Yachay Tech. The lab consists of two main programs:

1. **Insertion Sort (`insertion_sort.cpp`)**: Sorts a randomly generated array of alphabetic characters using the Insertion Sort algorithm. 
2. **Search Comparison (`search_compare.cpp`)**: Generates a sorted array of 10,000,000 random integers and measures the execution times to find a specific key using both Binary Search and Interpolation Search.

## Prerequisites
* A C++ compiler (e.g., `g++` for Linux distributions like Fedora).

## Compilation and Execution

### 1. Insertion Sort
